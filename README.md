## Run it

```sh
python3 main.py
```

## Entry

> Password, c. 2025. A secret word, written on paper and stuck to the very machine it was meant to protect.

## Alternatives that lost

1. “Single sock, 2021. Historians believe pairs existed, but no complete set has ever been found.” — the missing-sock joke is too familiar; it loses on freshness.
2. “Plastic fork, c. 2025. A ceremonial trident, used once, then buried for a thousand years.” — the fork is the obvious first object, and the label states the joke instead of trusting the reader.
3. “Group chat, 2024. A room where 47 humans said ‘lol’ every day and never once met in person.” — a group chat is not an object a museum puts a label beside, and the line explains its own joke.
